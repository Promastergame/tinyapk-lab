## <img src=".github/assets/icons/terminal.svg" width="20"> 2. Разрешённое использование инструментов Android

Вы имеете полное право использовать данный репозиторий совместно с инструментами платформы и сборки Android для компиляции, тестирования, упаковки, подписи и распространения производных проектов.

Поддерживаемые инструменты и утилиты включают (но не ограничиваются):

| Инструмент / Компонент | Назначение и роль в цепочке сборки |
| :--- | :--- |
| `android.jar` | Определения фреймворка API Android |
| `aapt2` | Инструмент упаковки ресурсов и сборки APK (Android Asset Packaging Tool) |
| `ecj` | Автономный компилятор Java от Eclipse (Eclipse Compiler for Java) |
| `d8` / `R8` | Компилятор байт-кода Java в Dex и оптимизатор/обфускатор ProGuard |
| `zipalign` | Инструмент выравнивания zip-архивов для оптимизации производительности APK |
| `apksigner` | Инструмент подписи и проверки цифровой подписи APK |
| `adb` и `keytool` | Отладочный мост Android (ADB) и управление ключами Java Keystore |

- **Распространение**: Убедитесь, что ваш порядок использования и распространения сторонних утилит соответствует правилам правообладателей.
