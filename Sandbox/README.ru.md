> [!NOTE]
> **Внутри нет проекта Gradle.** Компилируется вручную: `aapt2 -> ecj -> R8 -> zipalign -> apksigner`.

**Sandbox** — интерактивная песочница с падающим песком, физикой сыпучих материалов, жидкостей, теплопередачей, проращиванием семян и кулинарными реакциями.

---

## <img src="../.github/assets/icons/bolt.svg" width="20"> Что нового (Обновление 04.08.2026)

- <img src="../.github/assets/icons/link.svg" width="14"> **Двуязычный интерфейс (RU / EN)**: Полноценная поддержка английского языка, автоопределение языка системы и кнопка переключения `RU / EN` прямо на панели управления.
- <img src="../.github/assets/icons/book.svg" width="14"> **Авто-масштабирование текста**: Автоматическая подгонка шрифта наименований элементов (`paint.setTextSize(...)` с измерителем `measureText`), гарантирующая отсутствие наложений текста при любой ширине экрана.
- <img src="../.github/assets/icons/flask.svg" width="14"> **Старт с чистого листа и полная очистка**: Убрана начальная демо-сцена, поэтому песочница всегда открывается на 100% чистом холсте, а кнопка `Очистить` / `Clear` сбрасывает мир дочиста.
- <img src="../.github/assets/icons/image.svg" width="14"> **Адаптивная векторная иконка**: Новая векторная иконка приложения с неоновым тёмным фоном и песочными часами.
- <img src="../.github/assets/icons/terminal.svg" width="14"> **Единый инструмент сборки**: Полная интеграция со сборщиком репозитория `tools/windows/`.

## <img src="../.github/assets/icons/layers.svg" width="20"> Основные системы

| Система | Описание |
| :--- | :--- |
| **Порошки** | Песок, мука, соль, дрожжи и пепел осыпаются, накапливаются и реагируют с жидкостями или жаром. |
| **Жидкости** | Вода течёт, растекается по горизонтали, заполняет пустоты и превращается в пар. |
| **Жар** | Огонь, клетки жара, плиты и духовки запускают превращения соседних материалов. |
| **Рост** | Семена пшеницы и картошки могут расти на подходящей почве рядом с водой. |
| **Готовка** | Тесто выпекается в хлеб, картошка жарится, а комбинации ингредиентов создают новые продукты. |

## <img src="../.github/assets/icons/flask.svg" width="20"> Рецепты

| Рецепт | Результат |
| :--- | :--- |
| **Мука + Вода** | Тесто |
| **Тесто + Дрожжи** | Дрожжевое тесто |
| **Тесто + Духовка/Печь** | Хлеб |
| **Дрожжевое тесто + Печь** | Пышный хлеб |
| **Картошка + Плита / Сковорода** | Жареная картошка |
| **Картошка + Соль + Плита** | Вкусная картошка |
| **Пшеница + Жар** | Мука |

## <img src="../.github/assets/icons/terminal.svg" width="20"> Управление

- **Касание и перетаскивание**: Рисование выбранным материалом по холсту.
- **`-` и `+`**: Изменение радиуса кисти.
- **`Clear` / `Очистить`**: Сброс мира симуляции.
- **`RU / EN`**: Мгновенное переключение языка.
